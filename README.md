# Steam Frame PCVR for VRChat

**日本語** | [English](README.en.md)

Steam Frame単体でWindows版VRChatをVR表示するための、非公式セットアップツールです。
Windows PCから導入し、プレイ中の描画・処理はFrame内で行います。描画用PCへの接続は不要です。

本プロジェクトはValveおよびVRChatの公式製品ではなく、両社による承認・提携・支援を受けたものではありません。Steam、Steam Frame、VRChatなどの名称・商標は、それぞれの権利者に帰属します。

**開発：JITOME** · **アルファ版 · 独自部分はMIT** · **現在の配布版：0.3.7-alpha**

## できること

- **簡単インストール**：Windowsアプリから、Frameとのペアリング承認後に必要な部品の導入を進めます。
- **視線に合わせた描画**：視線の先の画質を優先するDynamic Foveated Rendering（DFR）を組み込みます。
- **動画・音声の改善**：H.264ハードウェアデコードと、動画プレーヤーの音声再開修正を含みます。
- **専用環境への導入**：互換ツールや設定を専用配置に分け、元の環境への影響を抑えます。同じアプリからアンインストールできます。
- **メモリー不足への備え**：必要に応じて、内蔵ストレージに8GiBの補助スワップ（メモリー不足時の退避領域）を追加できます。

## 用意するもの

| 必要なもの | 内容 |
|---|---|
| Steam Frame | 本人のSteamアカウントでログインし、開発者モードを有効にします。 |
| Windows PC | Windows x64用のインストーラーを実行します。Pythonや開発環境は不要です。 |
| ネットワーク | PCとFrameを同じネットワークへ接続します。部品の取得とVRChatの利用にはインターネット接続が必要です。 |
| 空き容量 | 本体のみで12GiB以上。補助スワップを使う場合は40GiB以上を推奨します。既存データによって必要量は増えます。 |

## インストール

1. [Releases](https://github.com/ji10me/SteamFrame_Standalone_PCVR_VRChat/releases/tag/v0.3.7-alpha)から **配布ZIPを1つ** ダウンロードし、Windowsで「すべて展開」して `FrameSetup.exe` を開きます。ZIPにはインストーラーと2つのライセンス文書が入っています。
2. Frameで開発者モードを有効にし、「設定 → 開発者 → 新しいホストをペアリング」を開きます。
3. WindowsでEXEを起動し、利用条件を確認して「インストール」を押します。
4. Frame側に表示される **`SteamFrame_Standalone_PCVR_VRChat`** の要求を承認します。
5. 完了後、FrameのSteamからVRChatを起動し、VRモードを選びます。

Steamの規約・ログイン、VRChatへのログインは本人が操作します。補助スワップを選んだ場合は、別ウィンドウでFrameのsudoパスワードを入力します。
Android版VRChatが見つかった場合は、削除の確認が表示されます。必要なデータを保管してから判断してください。
以前作成したペアリングキーでは、旧名が表示される場合があります。

詳しい手順、導入できない場合の対処、必要な互換ツールについては [インストール説明書](installer/README.ja.md) を参照してください。

## 使い方・アンインストール

**起動後、VRChat内のグラフィック設定で、アンチエイリアスを「OFF」、その他のグラフィック設定をすべて「LOW」にしてください。**

- **普段の起動**：導入後はFrameのSteamからVRChatをVRモードで起動します。
- **補助スワップ**：有効化はFrameの再起動までです。再起動後は同じEXEの「補助スワップ8GiB」から有効化します。
- **アンインストール**：VRChatを終了し、同じEXEの「アンインストール」を押します。ログイン情報などを含む専用の実行環境（Prefix）は退避し、Steam管理のゲーム本体や共有部品は残します。

## 現在の状態

開発用Frameでは、80人在室のインスタンスと、800MB超のワールド「COMPLEX7」で動作したとの報告があります。別々の利用報告であり、COMPLEX7で80人を検証したという意味ではありません。全アバター同時表示や、全てのワールドでの動作を保証しません。

0.3.7-alphaはProton Experimental 11に対応しました。更新後のProtonで導入が止まる問題と、VRChatのGCエラーで2段階認証の直後やワールド入室時に止まる問題に対処しています（[変更点](docs/RELEASE_0_3_7.md)）。FEXの版確認は従来どおり厳格です。0.3.6からビルド済みFEXを同梱し、初回のFEX本体コンパイルは不要です。DFR・動画・音声・補助スワップの実行構成は従来と同じです。
同じFrameで、EXE内と同一の処理による[アンインストール・再インストールとVR起動](docs/REINSTALL_0_3_4.md)を確認しました。
Windows実機での初回ペアリングから導入・管理者認証・削除までの通し操作と、別Frameでの動作は引き続き未検証です。

[最新版の変更と確認範囲](docs/RELEASE_0_3_6.md) · [検証範囲と未検証事項](docs/VALIDATION.md)
