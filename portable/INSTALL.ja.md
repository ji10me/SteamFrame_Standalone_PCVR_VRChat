## 1. 必要なものを準備する

- Steam Frame、インターネット接続、Frame上でコマンドを入力できる環境。
- Frame本体の空き容量が最低12GiB。ビルドや本人のゲーム用データの大きさによって追加容量が必要です。
- 次の4ファイル。すべて同じフォルダーへ保存してください。

| ファイル | 用途 |
|---|---|
| `frame-pcvr-kit.tar.gz` | 導入キット本体 |
| `frame-pcvr-kit.tar.gz.sha256` | 転送したファイルの破損を調べるチェックサム |
| `INSTALL.ja.md` | この説明書。キット内にも同じものがあります |
| `LICENSE.md` | MITライセンスと無保証の説明。導入前に確認します |

Macなどへ保存しただけではFrame側のシェルから参照できません。
その場合は、USBや設定済みのファイル転送方法で、4ファイルをFrame側の同じフォルダーへコピーしてください。

この版は標準Steamライブラリへのインストールを対象にしています。
外部ライブラリ、独自の互換ツール、既存の本プロジェクトの環境がある場合は、自動で上書きせず停止します。

## 2. 本人のSteamで必要なソフトをインストールする

| ソフト | Steam App ID |
|---|---|
| Windows版VRChat | 438100 |
| Proton Experimental | 1493710 |
| Proton EasyAntiCheat Runtime | 1826330 |
| FEX | 3127680 |
| SteamLinuxRuntime_4 | 4183110 |

Steamが依存ソフトとして導入するものもあります。VR表示にはFrame標準のSteamVRを使います。
このキットは、これらのソフトのインストールや規約への同意を代行しません。

1. SteamでVRChatのプロパティを開き、互換ツールを **Proton Experimental** にします。
2. 既に起動オプションが入っている場合は、その内容を本人の手元へ保存してください。
   初期準備は追加の起動オプションを空にして行います。
3. 本人のSteamからVRChatを一度起動し、必要な規約・初期設定を済ませます。
4. **VRChatを完全に終了します。導入が終わるまで起動しないでください。**

標準FEXでは、この最初の起動がEACエラーで止まる場合があります。
この段階は本人のゲーム用環境（Wine Prefix）とEasyAntiCheat用ディレクトリを初期作成するために必要です。
ディレクトリが作成されていなければ、後の前提チェックで停止します。空のフォルダーを手で作ってチェックを回避しないでください。

## 3. Frameのコマンド環境を確認する

Frameのターミナル、またはFrameへSSH接続したターミナルで実行します。

```sh
uname -s
uname -m
```

1行目が `Linux`、2行目が `aarch64` または `arm64` なら、対象のOS・CPU形式です。
`Darwin` ならMac側にいるので、ここでは先に進まずFrameへ接続してください。
この判定だけで実機がSteam Frameであることまで保証するものではありません。

ビルドには以下が必要です。後の `--check` で確認できます。

```text
Python 3.9以上、clang、clang++、cmake、ninja、ld.lld、git、patchelf、cp
Vulkan開発用ヘッダー・ライブラリ、Frame標準のFEX用rootfs
```

足りない場合、キットはOSのパッケージ追加や読み取り専用解除を自動実行しません。
表示された不足を確認し、そのFrameに合う開発環境を用意してから再開してください。
インストーラーはSteamを使う本人のユーザーで実行します。`sudo` を付けません。

## 4. キットを検査して展開する

ターミナルで、4ファイルを保存したフォルダーへ移動します。
ファイル管理画面からそのフォルダーのターミナルを開くか、`cd` に保存先のパスを指定してください。

```sh
ls frame-pcvr-kit.tar.gz frame-pcvr-kit.tar.gz.sha256
sha256sum -c frame-pcvr-kit.tar.gz.sha256
```

`frame-pcvr-kit.tar.gz: OK` と表示されれば、転送されたデータはチェックサムと一致しています。
`FAILED` やファイルがないという表示なら、同じフォルダーに正しい2ファイルがあるか確認し、必要なら受け取り直します。
チェックサムは署名ではないので、信頼できる相手から受け取ったキットを使ってください。

初めて展開する場所で次を実行します。以前の展開先へ重ねず、新しいフォルダーを使ってください。

```sh
tar -xzf frame-pcvr-kit.tar.gz
cd frame-pcvr-kit
python3 -B tools/install_portable.py --check
```

進めてよい結果は次のとおりです。

```json
{
  "ready": true,
  "errors": [],
  "no_changes": true
}
```

`--check` は読み取りだけで、ゲーム設定を変更しません。
`ready` が `false` なら、`errors` を確認し、「9. 困ったとき」を参照してください。
未確認のSteam/FEXビルドでは停止します。バージョンのチェックを削除して進めないでください。

## 5. インストールする

前提チェックが通り、VRChatが終了している状態で実行します。
展開後のキット直下の `LICENSE.md` を読み、条件に同意する場合だけ次へ進んでください。
`--accept-alpha-license` はその確認です。同意しない場合はインストール・利用を行わないでください。

```sh
python3 -B tools/install_portable.py --install --accept-alpha-license
```

FEXをFrame上で並列2でソースビルドするため、時間がかかります。
端末ごとの所要時間は未計測です。処理中は次のような段階名が表示されます。

```text
01-build-fex ...
02-stage ...
03-lookup ...
04-route ...
05-image ...
06-native ...
```

コンパイルの全出力は端末に流れず、私有ログへ保存されます。表示がしばらく増えないだけで完了とは判断しないでください。
ターミナルを閉じたりFrameをスリープさせたりせず、完了またはエラー表示を待ちます。

この処理は、本人の停止済みPrefixを本人のFrame内へ複製し、VRChat用の専用実行環境を作成します。
CPU実行、Vulkan接続・self-lookup、両眼サイズの画像一致試験が通ってからメモリ設定を適用します。
共有FEX・Proton・SteamVRや他ゲームを上書きせず、Steamの起動オプションも自動では変更しません。

成功すると `Prepared.` のメッセージと **`LAUNCH_OPTIONS.txt` の場所** が表示されます。
このファイルの場所を控えてください。場所に含まれるランダムな文字は端末・導入ごとに異なります。

## 6. Steamへ起動オプションを設定する

1. 完了時に表示された場所にある `LAUNCH_OPTIONS.txt` をテキストエディターで開きます。
2. ファイル内の **1行を先頭から最後まで** コピーします。最後の `%command%` も含めます。
3. Steamの **VRChat** のプロパティ→起動オプションへ、その1行を貼り付けます。
4. 互換ツールが **Proton Experimental** のままであることを確認します。

他人のFrameで生成した起動オプションは使いません。自分のインストール結果を使ってください。

実行環境は `~/.local/share/frame-pcvr/` 内に保存されます。
完了後にダウンロード元のキットを移動しても、専用実行環境はこの場所から起動します。
このディレクトリ内の `installations`・`candidates`・`c` は実行に使うため削除しないでください。

## 7. 初回のVR起動を確認する

1. FrameのSteamからVRChatを起動します。
2. 起動方法の選択が出たら **VRモード** を選びます。
3. 本人のSteam・VRChatアカウントで必要なログインを行います。
4. ホームで、立体表示・頭の動き・左右コントローラー・メニュー操作・音声を確認します。
5. 最初は小人数のワールドへ移動して試してください。

導入時の自動試験は、EACセッション・本人のログイン・VR表示・ワールド入室までの成功を確認するものではありません。
これらは導入したFrame上で確認します。

## 8. アバター表示を設定する

ログイン後、VRChatのパフォーマンス・アバター表示設定で次を指定してください。
これは本人のアカウント別の設定なので、キットでは自動変更しません。

| 項目 | 初期推奨値 |
|---|---|
| 最大アバター表示数 | 制限を有効にして5人 |
| 距離による非表示 | 有効にして4.5m |
| フレンドを常に表示 | ON |
| 手動Show Avatarを優先 | ON |
| アバター展開後容量上限 | 100MiB |
| アバターダウンロード容量上限 | 200MiB |

フレンドや手動表示の例外によって、表示数は5人を超えることがあります。
45人在室の実績は、この表示制限を使った結果です。45体のアバターを同時に通常表示した実績ではありません。

自動適用する実行設定は、pipeline lifetime有効、compiler 2本、VRAM報告2048MiB、Xalia無効、私有FEX DiskCache無効です。
RPO/FDM/UBO変換は使用しません。VRAMの報告値は実際のメモリ確保量の上限ではありません。

## 9. 困ったとき

| 表示・症状 | 確認すること |
|---|---|
| `Run on the ARM64 Linux Frame` | Macや別PCではなく、導入先Frameに接続しているか確認します。 |
| `Read LICENSE.md first` | 利用許諾の確認が必要です。読み、同意する場合に限り `--accept-alpha-license` を付けて導入します。 |
| `Missing build tool` / `Missing Frame system component` | 表示された開発ツール・標準部品が不足しています。前提環境を整えて `--check` を再実行します。 |
| `Install in the default Steam library` | 必要なソフトのインストール完了と、標準ライブラリへの配置を確認します。 |
| `Run your own VRChat once` | 本人のSteamから初回起動して、完全に終了します。本人のPrefix/EAC初期化が必要です。 |
| `Close VRChat completely` | VRChatとその起動処理が終わるまで待ちます。 |
| `Untested Steam build` | この版で未確認のFEX/Protonです。FEXはerrorsに出て停止します。Proton Experimentalはwarningsに出るだけで、必須のDXVK設定キーが確認できれば続行します。 |
| `An existing project Prefix is present` | 既存環境の上書きを防いでいます。再導入のためにPrefixを消さず、既存構成を確認します。 |
| `Kit manifest/hash mismatch` / `Unexpected files in kit` | 新しいフォルダーへ元のキットを展開し直します。展開内容へファイルを追加しないでください。 |
| `failed; private local log:` | その後に表示されたローカルログを本人が確認します。試験に失敗しているため、Steamへ起動オプションを設定しません。 |
| `Steam FEX changed since staging` | 標準FEXが導入後に更新されています。対応確認を行います。共有FEXへの上書きで回避しないでください。 |
| 大きいモニターとして表示される | Desktop / Non-VRではなく、VRモードを選んだか確認します。 |
| 黒画面・フリーズ・終了 | VRChatを終了し、まずホーム・小人数・上記のアバター制限で再確認します。別Frameでの動作確認が必要です。 |

導入途中で失敗した場合、作成済みの候補が残ることがあります。
再実行は上書きを防ぐため停止する場合があるので、ディレクトリの一括削除や連続再インストールは行わず、失敗した段階を確認してください。
ログには本人の識別情報が入る可能性があります。フォルダー全体をそのまま共有しないでください。

## 10. 標準に戻す・第三者へ渡さない

標準に戻すときはVRChatを終了し、VRChatの起動オプションを導入前の内容へ戻します。
導入前が空だった場合は空にします。共有ツールは上書きしていないため、復元作業は不要です。
標準へ戻すこと自体は、標準FEXでのVRChat動作を保証しません。

**インストール後の `~/.local/share/frame-pcvr/` は他人へ渡さないでください。**
そこには本人の認証済みPrefixやログができます。
元のキット・ソース・説明書・改変版も、権利者の明示的な許可なく第三者へ渡さないでください。
他の人が利用を希望する場合は、コピーを渡さず、権利者へ提供の可否を確認するよう案内してください。
この制限は本プロジェクト独自部分に対するもので、第三者ライセンスが付与する権利を制限しません。
外部部品の扱いは、キット内の `portable/THIRD_PARTY.md` を参照してください。
