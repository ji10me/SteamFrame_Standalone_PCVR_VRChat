# Windows版セットアップ

[日本語README](../README.md) / [English README](../README.en.md)

利用者向けの配布ZIPを展開し、`FrameSetup.exe`を起動します。
中身はEXE・`LICENSE.txt`・`THIRD_PARTY_LICENSES.txt`の3ファイルです。
詳しい導入・削除・補助スワップの操作は[インストール説明書](../installer/README.ja.md)を参照してください。

## 初回起動後の設定

VRChat内で**アンチエイリアスをOFF、その他のグラフィック設定をすべてLOW**にしてください。
最初はホームで両眼の立体表示・頭・両手・メニュー・音声を確認してください。
表示数や距離などの制限は、本人が利用するワールドに合わせて確認してください。

## 導入・削除の範囲

不足するゲーム本体と互換ツールは本人のSteamから取得します。本人の規約同意やログインは代行しません。
専用FEX・Proton・DFR・動画修正を本人のFrame内に作成し、通常のSteam起動に接続します。
共有互換ツールや他ゲームを上書きしません。

同じEXEでアンインストールできます。本人のPrefixはFrame内に保管し、Steam管理のゲーム本体・共有部品は残します。
Android版を削除する確認は導入途中に別途表示され、明示的に同意した場合だけ進みます。

## 確認済み・未検証

同じFrameの導入本体は、EXE内と同一のpayload・bootstrapをSSHで実行して確認しています。
Windows実機の初回ペアリング・GUI操作・管理者認証と、別Frameでの導入は未検証です。
詳細は[検証範囲](VALIDATION.md)と[0.3.4の再導入記録](REINSTALL_0_3_4.md)を参照してください。
未署名のアルファ版です。保護機能の無効化や除外登録を導入条件にしません。
