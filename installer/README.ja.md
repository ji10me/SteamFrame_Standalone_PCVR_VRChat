# Steam Frame PCVR for VRChat 0.3.7（Windows・アルファ版）

リポジトリ: [SteamFrame_Standalone_PCVR_VRChat](https://github.com/ji10me/SteamFrame_Standalone_PCVR_VRChat)。
0.3.7は、Steamで更新された新しいProton Experimentalでも警告を出して導入を続けられるようにした版です。0.3.6からビルド済みFEXを同梱しています。DFR・動画・音声・補助スワップの実行構成は従来と同じです。

Windowsのアプリから、DFR・H.264動画デコード・MF音声再開修正と、任意の8GiB補助スワップを導入します。
今回見送った、重い等倍画像補正は含みません。

## 導入する

1. 配布ZIPをダウンロードし、Windowsで「すべて展開」します。中の`FrameSetup.exe`を開いてください。インストーラーと`LICENSE.txt`・`THIRD_PARTY_LICENSES.txt`の3ファイルが入っています。
2. PCとFrameを同じネットワークへ接続します。
3. Frameで「設定 → システム → 開発者モード」を有効にし、「設定 → 開発者 → 新しいホストをペアリング」を開きます。
4. Windowsアプリで利用許諾を読み、同意チェックを付けて「インストール」を押します。
5. Frameに出る **SteamFrame_Standalone_PCVR_VRChat** の要求を承認します。承認後、VRChatの版を確認し、不足するSteam部品とPCVR版VRChatの取得・専用配置の作成・検査・起動設定の保存へ進みます。Steamの規約や認証が出た場合はFrameで確認してください。同意後は自動で続行します。
6. 補助スワップをONにした場合は、別ウィンドウでFrameのsudoパスワードを入力します。完了メッセージを確認してEnterを押します。
7. 完了後、FrameのSteamからVRChatを起動し、VRモードを選びます。Proton Experimentalの指定はセットアップが行います。VRChatへのログインや初回確認は本人が操作します。

**VRChat内のグラフィック設定で、アンチエイリアスをOFF、その他のグラフィック設定をすべてLOWにしてください。**

接続できない場合は、アプリの「Frame名 / IP」をFrameに表示されるアドレスへ変更してください。
以前このアプリとペアリングしたPCでは、再承認せずに接続できる場合があります。
ペアリングは[Valve公式の開発者向け経路](https://partner.steamgames.com/doc/steamhardware/steamframe/loadgames?l=english)を使います。

## 先にFrameで用意するもの

- Steamへの本人のログイン。
- インターネット接続。SteamからVRChatと互換ツールを取得します。
- VRChatを起動している場合は、完全に終了しておきます。
- 本体のみなら空き容量12GiB以上。補助スワップを使う場合は40GiB以上を推奨します。本人の既存Prefixが大きい場合は、さらに必要になることがあります。
- Frameに元から備わる開発ツール。OSパッケージや共有Steam部品は自動で変更しません。

Windows側にPythonや開発環境は不要です。通信に使うOpenSSHもEXEから専用配置へ展開します。Windows側は通常ユーザーで実行します。Frame側の補助スワップ操作だけは、別ウィンドウでsudo認証が必要です。
Proton Experimental、Proton EasyAntiCheat Runtime、FEX-Emu、SteamLinuxRuntime 4が不足していればSteamから取得します。
導入済みのツールはSteamの宣言済みライブラリ全体から探し、再ダウンロードせず使います。更新中・破損・不明な状態は流用しません。
確認済みバージョンと異なる場合は、その部品名を表示して停止します。導入済み判定とバージョン互換性の検査は別です。
Steamの取得画面が完了しても配置が現れない場合は、診断値と対処を表示して停止します。
通常の配布EXEはビルド済みFEXを検査して専用配置へ展開します。初回のFEX本体コンパイルと、そのためのgit・cmake・ninjaは不要です。
小さな接続用部品の作成とVulkanの検査はFrameで行うため、clang・clang++・lld・patchelfなど既存の開発ツールは引き続き使います。
インストール時だけ温度の停止上限を95℃にします。電力モード・クロック・プレイ中の温度制御は変更しません。

## Android版VRChatが入っている場合

インストーラーがAndroid版を検出すると、Windows側に「Android版をアンインストールしてからPCVR版を導入しますか？」という警告を表示します。
ローカルの設定・データを失う可能性があるため、必要なデータの保管を済ませてから選んでください。

- **はい:** FrameのSteamにAndroid版VRChatのアンインストールを要求します。削除完了を確認した後、PCVR版と不足する互換ツールの導入を続けます。
- **いいえ（初期選択）:** Android版を削除せずに、導入を中止します。先に自分でSteamから削除し、その後このインストーラーを再実行することもできます。

すでにWindows版が入っていれば、そのゲーム本体を使います。未導入ならSteamから取得します。
版が不明、APKとWindows版が混在、ダウンロード途中、複数ライブラリに存在する場合は、推測で削除せず停止します。
別Steamライブラリや、別途サイドロードしたAndroidアプリの削除には対応していません。
Android版の設定・ログインをPCVR版へ移す機能、自動バックアップやAndroid版への自動復帰はありません。
この削除確認は、PCVRセットアップの「アンインストール」ボタンとは別の、導入途中の確認です。

## 途中で止まった場合

- **VRChatの版・導入状態:** 表示された`StateFlags`とWindows実行ファイル・APKの確認結果を見てください。Steamのダウンロード完了とファイル整合性を確認します。不明な状態を推測して削除しません。
- **温度・RAM・容量・時間:** 停止した項目と実測値を個別に表示します。通常の配布EXEではFEX本体をコンパイルしません。95℃、空きRAM 1GiB未満、空き容量512MiB未満などで停止します。開始時には空きRAM 2GiB以上が必要です。
- **前回の導入が未完了:** 同じEXEの「アンインストール」で未完了の専用配置を片付けてから、インストールし直します。Steam管理のゲーム本体と共有互換ツールは残します。

停止理由が分からない場合は、画面に表示されたエラー文と数値を確認してください。認証情報や個人Prefixを他人へ渡す必要はありません。

## 元に戻す

1. VRChatを完全に終了します。
2. 同じ`FrameSetup.exe`で「アンインストール」を押します。
3. 必要ならFrameでペアリングを承認します。本アプリが作った補助スワップを使用中なら、別ウィンドウのsudo認証で解除します。その後、元のVRChat起動設定へ戻して専用の実行ファイルを削除します。

Steamから取得した共有互換ツールやPCVR版VRChat本体は残します。
導入時に確認して削除したAndroid版を、この操作で再インストールすることはありません。
以前のアルファ版がAndroidデータを退避した導入記録を持つ場合に限り、従来の復帰処理を維持しています。

ログイン情報・個人設定・キャッシュを含む本人の専用Prefixは、Frame内の
`~/.local/share/frame-pcvr-easy/retained/`へ保管します。自動では消しません。
必要がなくなったことを本人が確認してから削除できます。このフォルダーは他人に渡さないでください。
導入後に別のアプリや本人が起動設定を変更した場合は、その設定を保持して停止します。
Steamでインストールしたゲームや元のPrefix、他のMOD、キーボードは削除しません。
このPCのペアリングキーはWindowsのLocalAppData内に保管し、配布ZIPには含めません。
Frameの開発者設定で、このアプリのホスト承認を取り消すこともできます。

## 含める構成と確認範囲

DFRは視線中心の面積70%、中間85%、周辺2×2、診断点OFF。
0.2.3では、同じ起動情報を引き継いだ短命プロセスが現れると視線連携が終了する問題を修正しました。
最初に選んだゲームのPIDと開始時刻を追跡し、そのゲームが終了・置換された場合は連携も終了します。
0.2.4では、追跡対象の決定後に全プロセスを繰り返し探す処理を省き、対象PIDだけを確認します。

起動時のCPU割り当ては、対象スレッドの準備が遅れた場合に最大180秒・2秒間隔で再試行します。
コントローラーや視線の準備を待っている間も、音声用の割り当てを確認します。
Job Worker 7本をCPU3〜6、音声をCPU0〜7へ割り当てる、確認済みの8コア構成だけを対象にします。
別のCPU割り当てが設定されている場合は上書きせず、成功後の再適用もしません。
0.3.0には、この再試行と起動待ち中の適用を含めています。
ユーザー・タイトル・専用環境・開始時刻の照合は維持します。
DXVKのコンパイラスレッド2、VRAM容量の報告値2048MiB（全RAMの上限ではありません）、Xalia OFF、FEX DiskCache OFFを使います。
H.264だけハードウェアデコードを優先し、未合格のVP9・HEVCのハードウェア経路は無効にします。
動画の出力pool生成、drain後の再開、失敗後のエラー伝播と状態解除を修正した版です。
Wine MFには、再生速度0で開始した音声を1へ戻す際の再開修正を含めています。
以前に確認したCPU構成（8コア・Job Worker 7本と音声thread・元の割り当てCPU3〜7）が一致する場合だけ、
Job WorkerをCPU3〜6、音声をCPU0〜7に振り分けます。別の割り当てがある場合は維持します。
電力モード・解像度・クロックは変更しません。

本人の既存DFR配置が厳密なハッシュ検査に通れば、そのFrameのPrefixを専用配置へ複製し、個人設定を引き継ぎます。
初めて導入するFrameでは、本人のWindows用環境があれば使い、なければ専用の空の環境からProtonが初期化します。
既存Frameの個人データや視線校正を別のFrameへ配ることはしません。
別個体では視線校正とアバター表示制限を本人が確認してください。
混雑時の設定目安は表示数5、距離4.5m、ダウンロード200MiB・展開後50MiBです。
フレンド・個別表示の例外や人数によって負荷が変わるため、80人動作を保証するものではありません。

DFRと動画修正は元の実機試験で動作を確認しています。
このWindowsインストーラーによる別個体への一連の導入・長時間利用は、別途確認が必要です。
同じFrameでVRChat本体と依存ツールを削除し、Steamからの再取得・FEXの新規ビルド・EACの初期設定・VR表示・入室まで確認しました。
この試験はWindows EXEと同じ内蔵処理を、認証済みSSH経由で実行したものです。
0.3.4では既存依存部品を残した通常のアンインストールと再導入も確認しました。
写真の保管、共有部品の保持、8GiBスワップ再利用、VR起動・視線更新・音声対策のCPU割り当てを確認しています。
詳細は[0.3.4の再インストール記録](../docs/REINSTALL_0_3_4.md)を参照してください。
Android版検出時の警告、明示的な削除同意、対象限定、削除完了待ちは合成データとAPIモックで確認しました。
SteamによるVRChat本体の削除・PCVR版再取得は実機で確認しましたが、実際のAndroid版からの一連の入れ替えは未検証です。
別個体・別Steamアカウント、Windows実機の初回ペアリングからの通し操作も未検証です。
0.3.0の管理者認証ウィンドウを含むWindows実機での新規導入・削除の通し操作も、まだ未検証です。
起動・画面・音声の確認なしに、導入ボタンが完了しただけで性能や安定性が実証されたとは扱いません。


## 8GiB補助スワップ

インストール画面の「8GiB補助スワップも有効化」をONにすると、本体の導入後に準備が始まります。
Frame内の空き容量は40GiB以上を推奨します。スワップ準備時点で28GiB以上の空きとext4が必要です。
別の認証ウィンドウが開いたら、**Frameのsteamosユーザーのsudoパスワードをそのウィンドウで入力**します。
入力は通常画面に表示されません。完了メッセージを確認してEnterでウィンドウを閉じてください。
このアプリがパスワードを保存・配布する仕組みはありません。

- 既存の圧縮スワップを優先し、追加8GiBは優先度10の予備にします。
- **一時適用です。Frame再起動後は、同じEXEの「補助スワップ8GiB」で再度有効化してください。**
- 管理者認証を中止してもPCVR本体の導入は残ります。上のボタンから再試行できます。
- 既に十分な容量の補助スワップがある場合は追加せず、その設定を保持します。自分で作った既存スワップを本アプリが削除することもありません。
- アンインストール時には本アプリが作った有効なスワップだけを解除してからファイルを削除します。解除にも管理者認証が必要です。
- スワップを使用中のまま手作業でファイルを削除しないでください。

メモリー不足で落ちるのを減らすための予備です。RAMの速度やGPUメモリー容量が増えるわけではありません。
ストレージへの読み戻しによって、カクつきや長い待ちが生じる場合があります。
